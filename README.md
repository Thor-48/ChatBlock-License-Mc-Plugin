# ChatBlock

A lightweight Minecraft plugin for **1.21+** that allows server administrators to temporarily mute or block the global server chat, while letting authorized players continue speaking.

## Features
* Toggle global server chat on or off with a single command.
* Bypass permission for staff members or VIPs so they can still write while chat is muted.
* Built specifically for Minecraft **1.21**.

## Commands

| Command | Aliases | Description | Permission |
| :--- | :--- | :--- | :--- |
| `/chatblock [on\|off]` | `/cb` | Toggle the global chat block. | `chatblock.toggle` |

## Permissions

| Permission | Description | Default |
| :--- | :--- | :--- |
| `chatblock.toggle` | Allows using `/chatblock`. | `op` |
| `chatblock.bypass` | Allows chatting while ChatBlock is enabled. | `false` |

## Installation
1. Download the latest `.jar` file from [Modrinth](https://modrinth.com/plugin/chatblock-why_luca/).
2. Place the file into your server's `plugins` folder.
3. Restart or reload your server.
